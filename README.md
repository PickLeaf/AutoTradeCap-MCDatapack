# Minecraft Datapack
Added automatic trading enchantment to the Wither Skeleton Skull, Using dispenser to put it on Villager allows for automatic trading.
Place Barrel on top of head of Villager, And provide the items they buy, Traded items will drop.
Only the first trade item can be automatic traded, And immerse the Villager'legs in fire to cycles through the trade list.
# 我的世界数据包
为凋灵骷髅头添加了自动交易附魔，使用发射器为村民带上就能自动交易。
在村民头上放木桶提供村民收购的物品，交易出的物品会被村民丢出。
只能自动交易第一项交易项，将村民腿部浸入火焰中以循环交易列表。
